# Template Image Instructions

This folder should contain:

1. **template.png** (1080 x 1365 px)
   - Your custom background template image
   - Should be designed with:
     - A central area for the circular photo (around y: 480px, diameter: ~560px)
     - Top section for "I'LL BE THERE" title
     - Bottom section for name and role text
   - Recommended colors: CodeConnect blue (#1E90FF), orange (#FF8C42), white

2. **logo.png** (optional)
   - CodeConnect logo for branding
   - Can be added to the template design

## Note
If template.png is not provided, the app will automatically generate a beautiful gradient background with decorative elements.

## Creating Your Template

You can create your template using:
- Canva (1080 x 1365 px canvas)
- Figma
- Photoshop
- Any image editor

Make sure to:
- Leave space in the center for the circular photo
- Keep text areas clear (top for title, bottom for name/role)
- Use high-resolution images for best quality
- Save as PNG for transparency support
